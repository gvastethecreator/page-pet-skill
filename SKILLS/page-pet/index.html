Each pose is one full-character drawing. The runtime picks the nearest gaze cell as the pointer moves, then plays a drawn reaction on click. Open the playground or install the skill.

Install

npx skills add gvastethecreator/page-pet-skill --skill page-pet

Local playground from a clone:

python ./SKILLS/page-pet/scripts/serve.py

Then open http://127.0.0.1:4177/playground/. The server binds to loopback. This GitHub Pages site is the same static files without that server.

Limits

  • Playground chrome is Spanish. Public docs are American English.
  • New art uses Codex's built-in image tool. This site does not generate images.
  • Frame counts and hashes are technical gates. They do not approve art.
  • GitHub Pages cannot run the Python builders.
