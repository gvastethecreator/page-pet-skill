# Security

Please do not open public issues for sensitive security reports.

If you find a vulnerability or unsafe behavior in this skill pack, contact the maintainer privately with the affected file, reproduction steps, and expected impact. Do not include secrets, private keys, access tokens, or private user data in reports.

The playground server binds to loopback only. Page-pet packs are same-origin static files. Do not load remote manifests or images through the custom element.
